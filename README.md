# ChatBot — Викторина и Новости в Telegram

Учебный проект: Telegram-бот, который задаёт вопросы викторины и показывает новости из RSS-лент.

## Что умеет

- **Викторина:** бот задаёт вопросы, проверяет ответы, ведёт счёт.
- **Новости:** бот берёт новости из RSS (e1.ru), показывает пользователю.
- **Многопользовательность:** каждый пользователь играет свою викторину (по `chatId`).

## Технологии

- **Java 25** (или 21).
- **Maven** — сборка.
- **JUnit 5 + Mockito** — тесты.
- **TelegramBots** — Telegram API.
- **Rome** — парсинг RSS.
